# PIMS — ICT기금 사용자 중심 AX서비스 기획 개요

> 본 문서는 작성 시점(2026-05-20)의 의사결정 결과이며, 구현 진행에 따라 갱신한다.

## 1. 프로젝트 정체성

- **공식 명칭**: ICT기금 사용자 중심 AX서비스 구축 계획(안)
- **시스템 별칭**: (가칭) PIMS — ICT기금 사업정보관리시스템
- **주관**: ICT기금관리본부 기금사업성과팀
- **원본 기획서**: `붙임3. 사업계획서(ICT기금 사용자 서비스 구축).hwpx`

## 2. 추진 배경

- 기금 규정·관련 법령의 **지능형 해석 지원 체계** 부재 → 복잡한 질의에 대한 해석 전문성·일관성 확보 필요
- 동일 아이템의 **중복지원 방지**를 위한 사전 조회·통합 정보 제공 필요
- 사용자 중심 정보 활용성 강화 (수혜자가 흩어진 공고를 직접 찾아다니는 비효율 해소)

## 5. 데이터 민감도 분류

- **공개 가능** — 본 시스템이 다루는 자료(법령·공고·내부 규정 일부). 따라서 외부 상용 API·외부 클라우드(Vercel·Supabase) 사용 전제.
- 민감 데이터(예: 사업자 식별정보, 인건비 등)는 ③ 중복수혜 조회에서 부분적으로 사용 → 별도 마스킹·암호화 정책으로 처리.
